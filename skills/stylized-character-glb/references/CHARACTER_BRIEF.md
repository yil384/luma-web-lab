# Character brief template

Fill before each run. Use only original characters and permitted images.

| Field | Value |
| --- | --- |
| Character ID and revision | `character-001 / v01` |
| Media owner / license | TBD |
| Runtime / deliverable | Mobile WebGL / static or rigged GLB |
| Face | Eyes, eyelids, nose depth, lips, jaw, cheeks, ears |
| Hair | Color, massed locks, back silhouette |
| Outfit | Palette, opaque layer structure, accessories |
| Body proportions | Head-to-body ratio, limb length, A-pose |
| Camera / lighting | Frontal, studio, near-orthographic |
| Image source | Filename, SHA-256, resolution, mask check |
| Reconstruction | Tool/version, seed/settings, license and cost |
| Output | GLB SHA-256, size, mesh and texture counts |
| QA | Front / 45° / side / back, mobile test, reviewer |

Version-control every iteration and its visual rejects. Do not put real-person or private photos into public repositories.
